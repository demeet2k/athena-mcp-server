# 08 · Limits, falsifiers, negatives

## What the framework does not claim

- It does not claim any tradition is true, false, or the same as another. A module is a description; an isomorphism class is a coincidence of pattern tokens; a bridge is a mapping with declared loss.
- It does not authorise, teach or reconstruct a practice. RITE slots hold opcodes and a one-line cost/effect; nothing operative is encoded, and the VM's `invoke` returns a state trace with `execution_authority: NONE`.
- It does not predict. `divine` is a seeded hash over a finite space; `judge` is a function from a caller's score to a named destination; both HOLD on medical, legal, financial and safety-critical use.
- It does not date anything. Standing is per module and per slot; a MODERN_RECONSTRUCTION cannot carry a 🟢 without a locus, and corpus-only material is 🟠 everywhere.

## Falsifiers

1. A tradition that cannot be written into the twelve slots at all, with every slot ⊥. (Australian material comes closest: ORACLE ⊥, and BOOT only as ETERNAL with phases.)
2. A cosmogony that is not a walk on the seven-stage alphabet: a stage the alphabet cannot name. Every module so far walks it; a genuine eighth stage would extend the ABI.
3. A ritual whose source-attested order violates the lint (invocation before boundary) *as the tradition's own rule*, not as a corrupt text. The lint would then be a Western bias and would need a per-module override.
4. A divination device whose set-aside unit is counted, or whose sample space is not finite.
5. A ledger that is neither balance, counter, binary, cyclic, ancestral, tiered nor none.
6. Two modules with identical twelve-token signatures from unrelated families. The signature would then be too coarse to carry the unification and would need a finer token alphabet.
7. A bridge the strata runtime accepts as an equivalence. It cannot by construction; if it did, the membrane would be broken.

## Coarseness of the signature

The pattern tokens are deliberately coarse. `MEMMAP` reads addressing, depth and realm count, not the realms' names; `PROC` reads scheduler class, agent count and root count, not who the agents are; `RITE` reads the first protocol's flags. Coarseness is what makes classes non-trivial across families, and it is also why a class is never an identity: two modules in the same BOOT class can differ in every event. The service matrix shows the tokens; the module catalogue shows what they abstract from.

## Coverage

Coverage is bounded by what the sources read say, not by what a tradition contains. A ⊥ is a statement about the sources in `sources`, and the way to remove it is to add a source and a locus, not to fill the slot. The encoding brief (`ENCODING_BRIEF.md`) is the contract for doing so.
