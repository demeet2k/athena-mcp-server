# KC144 executable polyatlas

`athena_mcp.kc144_polyatlas` adds a source-bound, standard-library-only navigation layer to the existing KC144 command hub. It preserves the immutable `GID001..GID144` host while projecting each seat through four simultaneous decompositions:

- `12 × 12` matrix;
- `27 + 117`, with the relation body factored as `13 × 9`;
- `6 × 3 × 8` cubed-sphere host plus eighteen reserved KC162 portal fibres;
- `4 × 36 = 4 × (27 + 9)` elemental/core-closure view.

The module also compiles the C01–C16 chapter/shelf Rosetta address, the exact `27 × 27 = 729` locus space, KC27 ternary and mirror laws, the `1+6+12+8` shell census, and exact transport throughout the odd `N=3m` resolution family. Resolution transport never rounds: it returns a rational destination or a two-station barycentric support whose weights sum to one.

## Spherical geometry

Each active KC144 seat owns one gnomonic rectangle on a cube face. Its centroid is projected to the sphere, its Riemann coordinate is emitted, and its exact solid-angle rectangle is integrated as a radial wedge. Validation checks:

`ΣΩ = 4π`, `ΣA = 4πR²`, and `ΣV = 4πR³/3`.

The spherical proximity graph is explicitly a deterministic navigation graph. Neither proximity nor reachability is treated as proof.

## Source and authority boundary

The compiled laws are linked to three Google Docs snapshots identified in the runtime manifest. The implementation validates its own finite arithmetic and graph transformations. It does not convert source repetition, local test success, coordinate coincidence, or graph adjacency into empirical truth, independent witness status, causal evidence, or promotion authority.
