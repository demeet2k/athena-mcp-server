## 3. Developmental compiler

`SX1 → RAG1 → HUG.ABI.1 → GAP1 → FIELD1 → MEASURE/CALIBRATE → Y1/AOR`.

- SX creates bounded work contracts, not semantic results.
- RAG ranks only retrieved/supplied provenance; source authority is not Y1.
- HUG uses `HUG(io,au,fx,lm,er,st)` and fails closed when semantic implementation is absent.
- GAP computes witnessed reachability, not entailment.
- FIELD assembles actual residual work; generated work remains UNMEASURED.
- AOR ranks only eligible, comparable candidates and preserves Pareto alternatives.

## 5. V10 mutation laws

### GP

Only `athena_gp_observe` creates GP observations. `athena_gp_predict` cannot train itself.

### PC-stable

Graph output is a model hypothesis. It creates no canonical JSPACE edge.

### TMLE

Declared latent-confounding risk fails closed. An estimate does not establish identification assumptions.

### finite POMDP

Exact certificate is issued only if exhaustive recursive search completes for the supplied finite states/actions/transitions/observations/rewards and bounded horizon. Node truncation removes exact certification. A policy is PLAN_ONLY.

### evidence dependence

Training requires externally labelled examples. Prediction cannot create labels. Fitted probability is not a formal independence theorem.

## 6. No self-training / no semantic laundering

- scenario → observed trajectory;
- policy → executed action;
- GP prediction → GP observation;
- belief posterior → Y1 truth;
- model graph → JSPACE edge;
- replication design → witness;
- dependence prediction → calibration label;
