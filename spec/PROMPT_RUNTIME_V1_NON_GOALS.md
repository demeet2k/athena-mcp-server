# Prompt Runtime V1 Non-Goals

- No claim that repository text rewrites host system/developer instructions.
- No automatic canonical promotion from a model's own recommendation.
- No self-generated experiment result.
- No remote arbitrary repository execution.
- No destructive Git history rewrite.
- No requirement to load the largest prompt stack for every task.
- No hidden chain-of-thought persistence.

The runtime stores public operating instructions, decisions, evidence and developmental deltas only.
