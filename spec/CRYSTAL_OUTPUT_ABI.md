# ATHENA CRYSTAL OUTPUT ABI v1

Every consequential visible output is a versioned semantic object plus one or more native manifestations. No output is canonical as unindexed prose.

## Identity fiber

`I(x)=<CID,OID,VID,MID,CRYS,EID,SID>` with all identifiers semantically distinct.

- CID: functional capability identity.
- OID: semantic object identity.
- VID: immutable version identity with parent VID.
- MID: carrier manifestation identity.
- CRYS: crystal-manifest identity.
- EID: causal event identity.
- SID: KC144 station identity.

## Exact lexeme fiber

For lexeme k:

`K_k=<SID_g,OID,VID,MID,P,S,T,[c0,c1)>`.

The full polycoordinate lexeme is not stored by duplicating every chart on every token. It is a fiber join:

`Pi(token_k)=K_k ⊕ Atlas(OID,VID,MID)`.

Thus every lexeme inherits the object's simultaneous JSPACE/SCALE/lineage/time/liminal/CUT/evidence/native coordinate state while retaining exact carrier offsets.

## Output compilation

`CRYSTALLIZE_OUTPUT = Identity ∘ CASVersion ∘ Manifest ∘ LexemeIndex ∘ MathRegister ∘ GraphDelta ∘ HypergraphDelta ∘ PolyAtlas ∘ TimeBundle ∘ CrystalManifest ∘ DerivedHeader`.

The body is indexed first. The derived header is then stored as a separate manifestation because putting a header containing CRYS/MID inside the content whose digest defines CRYS/MID would create identity recursion.

## Unknown law

`UNKNOWN != N/A`.

UNKNOWN: chart is potentially applicable but no lawful coordinate has been resolved.
N/A: chart is proven inapplicable to this object/manifestation.
RESOLVED: a lawful value is present with source/transform provenance.
PARTIAL/HOLD: a value exists below promotion threshold or is blocked.
