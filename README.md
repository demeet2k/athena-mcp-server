## Authority and transaction domains

Three state domains are intentionally independent:

- semantic object/version state: expected-VID CAS;
- Git state: expected-Git-head CAS;
- collective topology: expected-topology-version CAS.

A stale write in one domain must not mutate either of the other two. Topology→JSPACE projection uses a recovery saga; SQLite+Git are never represented as one atomic transaction. Semantic compensation never pretends to rewrite Git history.
