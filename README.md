# Collective Runtime V6 — Active Discovery + Stochastic Control

V6 attacks the next residual without relabeling adjacent approximations as solved.

## ΩNONLINEAR / ΩOOD

- `athena_ood_observe`
- `athena_ood_score`
- `athena_nonlinear_predict`
- `athena_nonlinear_observe`

V6 adds a transparent degree-2 polynomial feature lift on top of V5's full-covariance Bayesian model. Raw-feature context distributions are tracked separately and scored with ridge-regularized Mahalanobis geometry plus unseen-feature pressure. OOD pressure widens inherited predictive intervals instead of becoming a truth label.

`NONLINEAR_BASIS != UNIVERSAL_INFERENCE` and `OOD_SCORE != FACTUAL_FALSEHOOD`.

## ΩEXPERIMENT-GENERATOR

- `athena_experiment_generate`

V6 enumerates a finite caller-declared factor space, derives binary-outcome likelihoods only from declared base probabilities and `factor=value` effects, preserves cost/risk/feasibility/ethics metadata, and delegates ranking to V5 expected-information-gain design.

Generated experiments remain `DESIGN_ONLY`; ethics-blocked combinations remain visible for audit rather than disappearing.

## ΩCAUSAL-ID

- `athena_causal_identify`

For a caller-supplied directed causal graph, V6 searches minimal observed back-door adjustment sets by removing treatment out-edges, excluding treatment descendants, moralizing the relevant ancestral graph, deleting conditioned nodes and testing d-separation/reachability.

`IDENTIFIED_BACKDOOR` means identified **under the supplied DAG and assumptions**. Explicit latent-confounding risk fails closed.

## ΩHIGHER-ORDER

- `athena_interaction_higher_order`

V6 computes order-2 through order-4 binary factorial inclusion-exclusion contrasts. Every `2^k` cell is required; missing cells remain `UNIDENTIFIED`. Numerical interaction remains associational unless design confidence supports stronger causal interpretation.

## ΩSTOCHASTIC-TRANSITION / ΩMPC

- `athena_transition_distribution`
- `athena_mpc_plan`

V6 reconstructs multivariate empirical action-conditioned context-delta means and covariance from actual V5 transition observations, with shrinkage toward no change while evidence is sparse. MPC uses these distributions for bounded risk-adjusted receding-horizon planning.

MPC is `PLAN_ONLY`: execute the first authorized action, observe reality, then replan. It creates no transition observations by itself.

## ΩCERTIFIED-SCHEDULE

- `athena_schedule_certified`

For small fully declared task sets, V6 exhaustively enumerates feasible schedules under dependencies, worker capability/capacity, durations, horizon, deadlines and explicit resource budgets. `EXACT_ENUMERATION_CERTIFIED` is returned only when exhaustive search completes. Node truncation or task-count fallback removes the certificate. Missing constrained resource costs also remove exact certification: `UNKNOWN_COST != ZERO_COST`.

## ΩHERMETIC-CAPSULE

- `athena_witness_capsule`

When Linux bubblewrap is available, V6 can execute the restricted repository unittest grammar in a stronger capsule with read-only repository bind, isolated network namespace, tmpfs scratch and isolated Python. If bubblewrap is unavailable, the tool returns `HERMETIC_UNAVAILABLE` with `executed=false`; it never silently falls back to the weaker witness cell.

Even when executed, `hermetic=true` describes the declared namespace controls actually used; it is not a proof against kernel/runtime vulnerabilities.

## ΩPARETO-BANDIT

- `athena_pareto_bandit_select`

Interval-valued objective candidates are robustly dominated only when one candidate's worst-case metric values dominate another's best-case values across every directed objective. Remaining candidates form an interval-possible frontier; uncertainty may select a frontier member for measurement without imposing one universal value ordering.

## ΩREPLICATION / FALSIFICATION GRAPH

- `athena_claim_witness`
- `athena_claim_state`

V6 adds science-shadow claims and provenance-bearing TEST/REPLICATION/FALSIFIER witnesses with explicit independence keys. Derived states include `PRELIMINARY_SUPPORT`, `REPLICATED_SUPPORT`, `FALSIFICATION_SIGNAL` and `CONTESTED`. These are evidence-navigation states and never silently mutate canonical semantic objects.
