## OG — order-constrained finite DAG posterior

`athena_ordered_dag_posterior` enumerates the complete finite DAG family consistent with a **caller-declared topological order** over at most five variables. Each node is scored with the implemented linear-Gaussian BIC local score plus an independent edge-prior term; graph weights are normalized exactly over that bounded family.

Optional externally labelled calibration examples may map raw edge posterior coordinates through the V15 isotonic reliability layer.

`ORDER_CONSTRAINED_DAG_POSTERIOR != GENERAL_CAUSAL_GRAPH_POSTERIOR`.

`CALLER_ORDER != DISCOVERED_CAUSAL_ORDER`.

`CALIBRATED_RELIABILITY != CANONICAL_JSPACE_EDGE`.

No latent-confounder or unrestricted graph-order discovery is claimed.

## MH — bounded multistage cross-fitted sequential DR

`athena_longitudinal_dr_multistage_crossfit` supports one through six binary treatment stages under explicit caller-declared decision-time histories. Histories that include the current/future treatment or outcome fail closed.

Nuisance models are cross-fit over held-out folds and supplied policies receive sequential regression plus inverse-propensity augmentation.

`BOUNDED_MULTISTAGE_CROSS_FITTED_DR != ARBITRARY_HORIZON_LONGITUDINAL_THEOREM`.

`CALLER_DECLARED_HISTORY != VERIFIED_REAL_WORLD_CHRONOLOGY`.

## EF — learned approximation-error field

`athena_approx_error_field` learns a bounded RBF-kernel approximation-error field from explicit absolute-error witnesses. It computes held-out residuals and reports a selected residual quantile added to the fitted query error, plus nearest-witness support distance and optional support-radius membership.

`CV_RESIDUAL_QUANTILE != DISTRIBUTION_FREE_ERROR_CERTIFICATE`.

`LEARNED_ERROR_FIELD != GLOBAL_LIPSCHITZ_CERTIFICATE`.

`IN_SUPPORT_RADIUS != WORLD_REGIME_MATCH`.

Unsupported/OOD geometry remains explicit.

## NR — coupled finite model-family robust policy evaluation

`athena_coupled_model_robust_policy` evaluates a supplied finite policy set against a supplied finite family of complete state/action/reward/transition models. One adversarial model identity is fixed for the whole finite horizon, making the ambiguity coupled across state/time rather than state-action rectangular.

The implementation returns minimum-model value, prior-weighted value, worst regret, weighted regret and per-model values for each supplied policy.

`FINITE_FIXED_MODEL_FAMILY_POLICY_EVALUATION != GENERAL_NONRECTANGULAR_DRO_OPTIMIZATION`.

`SUPPLIED_POLICY_SET_EVALUATION != OPTIMIZATION_OVER_ALL_POLICIES`.
