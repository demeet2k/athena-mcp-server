# ATHENA NEXT Scout Economy V5

Use this skill after rolling NEXT V1, Breadth V2, Scout V3, and Allocation V4 are available and the user wants sustained mass orchestration with bounded resource consumption.

## Coordinate

`ATHENA.KC144::GITΩ::NEXT::SCOUT-ECONOMY::V5`

## Flow

```text
Q1 remains sole mutable focus
→ Q2/Q3 expose Breadth prep plans
→ read active Message Board scout claims
→ subtract protected reserve vector
→ estimate remaining prep cost/value
→ enumerate feasible bounded subsets
→ preserve Pareto-efficient allocations
→ recommend one policy-optimal set or explicit tie
→ separately call athena_next_scout_claim for actual ownership
```

## Resource vector

V5 uses deterministic planning estimates for:

- tokens
- minutes
- tool calls
- coordination load
- Git integration risk

These are **not observed usage or billing measurements**. They are routing priors only.

## Value vector

- expected reconstruction reduction
- expected blocker removal
- expected information gain

These are planning values, not truth/evidence scores.

## Reserve law

Budget minus reserve is the spendable planning envelope. Active scouts consume that envelope before any new recommendation. If an active scout references an unknown prep plan/resource profile, fail closed rather than assuming zero cost.

## Tie law

Equal optimal resource allocations remain `AMBIGUOUS_ECONOMIC_ALLOCATION`. An explicit choice may select only a member of the already-computed optimal family.

## Authority

- V5 may recommend prep plan IDs.
- Message Board owns claims.
- Scout V3 owns claim/return orchestration.
- Q1 remains the only mutable focus quest.
- V5 cannot execute, promote, merge, release, deploy, or establish evidence.

## Core laws

- `ECONOMIC_ALLOCATION != CLAIM`
- `PLANNING_COST_ESTIMATE != OBSERVED_RESOURCE_CONSUMPTION`
- `RESERVE_VECTOR_IS_NOT_SPENDABLE`
- `ACTIVE_SCOUTS_CONSUME_RESOURCE_BUDGET_FIRST`
- `PARETO_TIE != HIDDEN_TIE_BREAK`
- `ROUTING_VALUE != EVIDENCE_OR_TRUTH`
