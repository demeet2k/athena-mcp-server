# Architecture

0. Git causal persistence — literal history and checkpoint CAS.
1. CCR — deterministic functional identity for every reusable capability.
2. JSPACE — typed semantic multigraph over objects, versions, events, agents, manifestations and mutations.
3. SCALE — `S0 event → S1 delta → S2 relation → S3 motif → S4 generator → S5 organ law`.
4. KC144 — immutable 12×12 host topology; coordinate is never identity.
5. POLYCOORDINATE / TRANSFORM RUNTIME — chart registry plus explicit LOOKUP vs executable DERIVATION semantics; holonomy claims require all-derivational closed routes.
6. AΩR.3 — uncertainty-safe developmental compiler over extraction, dependency graph, gates, residuals, scalar and Pareto frontiers, reward/reallocation, decision explanation, persisted AORRUN receipts and deterministic replay.
7. EMISSION GATEWAY — crystallize exact body, assemble HEADER+BODY, create exact visible-byte emission manifestation, verify ENV digest across transport boundaries.
8. Runtime — hydrate, conditional writes, telemetry, adoption, replayable session state and composed tool dispatch.

AΩR closed loop:

`RECONSTRUCT → EXTRACT → RETRIEVE → HUG → GRAPH → GAP → COMPILE → MEASURE → TEST → OBSERVE → REPAIR → RETEST → VERIFY → REWARD → REALLOCATE → OUTPUT → SUCCESSOR → REPLAY`

AΩR formulas are evaluated only when all required operands are KNOWN:

- residual: `severity * leverage * information_gain / cost`
- frontier: `readiness * gain * independence * bridge / cost`
- successor: `DeltaJ * information_gain * bridge * option_value / cost`
- reward positive: `DeltaJ,evidence,connection,replay,navigation,reconstruction,implementation,novelty`
- reward negative: `duplicate,fake,bloat,unsupported,unhandled_contradiction,coordinate_loss`

`UNKNOWN != 0`: incomplete formulas are non-rankable and route to the measurement plan.

A candidate can enter automatic execution/successor selection only when dependency-ready and promotion-gate-passing. Claimed tests require procedure+observation+result+witness; claimed persistence requires commit+receipt+verify; required coordinate gaps and active fake/unsupported/unhandled contradiction block promotion.

Scalar successor selection is complemented by a Pareto successor frontier over `DeltaJ, information_gain, bridge, option_value, cost`; non-dominated alternatives remain visible even when one scalar `next` wins. Decision explanation records why each alternative was selected, blocked, tied or outranked.

Every persisted orchestration produces `AORRUN=<input,output,decision_digest,EID,...>`. Replay recompiles stored input and verifies routing digest, `next`, `grow` and Pareto alternatives.

Non-negotiable laws:
- same namespace != same lineage
- delivered != hydrated != consumed != adopted
- coordinate != identity
- tested != current != canonical != integrated
- UNKNOWN != N/A != 0
- LOOKUP != DERIVATION
- claimed test != witnessed test
- attempted write != verified persistence
- replayable claim != replay witness
- hibernate != erase
- compression requires lawful reconstruction + RETURN
- visible output after ENV finalization must not be mutated without invalidating the emission digest
- global mutations require next-cycle adoption
- public telemetry never stores private chain-of-thought
